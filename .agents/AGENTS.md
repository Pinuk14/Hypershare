# HyperShare Workspace Agent Rules

## MANDATORY AGENT RULE: FILESTRUCTURE INDEX MAINTENANCE

Whenever you make **ANY** file addition, deletion, modification, refactoring, or re-organization in this workspace:
1. You **MUST** update `Filestructure.md` in the root of the repository (`b:\All Projects\Hypershare\Filestructure.md`).
2. Update the directory tree or file responsibilities section if any files were added, deleted, or moved.
3. Append a new entry to the `Change Log` section in `Filestructure.md` detailing the timestamp, action, and summary of changes made.
